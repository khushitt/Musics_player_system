# 🎵 Music Player

A simple **Music Player Web Application** developed using **Python and Flask**, with a frontend built using **HTML, CSS, and JavaScript**. The project demonstrates how music playlists can be managed using basic **Data Structures and Algorithms (DSA)** concepts such as stacks, queues, and list-based navigation.

## 📌 Project Overview

This project is designed to simulate the basic functionality of a music player. Users can manage and navigate through songs using options such as **Play, Next, Previous, and Playlist Management**.

The main purpose of this project is to combine **web development with Python programming and DSA concepts** to create a practical application.

## ✨ Features

- 🎵 Play songs from a playlist
- ⏭️ Move to the next song
- ⏮️ Move to the previous song
- 📃 Manage songs in a playlist
- 🔄 Navigate between songs
- 🎧 Simple and user-friendly music player interface
- 🐍 Python Flask backend
- 🌐 HTML, CSS, and JavaScript frontend
- 🧠 Uses basic DSA concepts for playlist navigation

## 🧠 DSA Concept Used

The project uses basic data structure concepts to manage the playlist and song navigation.

For example:

- **List** → stores songs in the playlist.
- **Stack concept** → can be used to keep track of previously played songs.
- **Queue concept** → can be used to manage songs waiting to be played.
- **Index-based navigation** → helps move between the current, next, and previous songs.

This makes the project useful for understanding how DSA concepts can be applied to a real-world application.
